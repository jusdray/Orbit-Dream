# Figma Services Reference Findings

The supplied desktop frame uses a deep blue-black field (`#011418`) with a faint, cyan-lit network topology layer. The layout is a two-column composition: left-side service navigation and scroll indicator, with a right-side content plane. The reference establishes Nohemi typography, Signal Cyan (`#04d9ff`) for active states, medium-gray supporting copy, translucent dark glass solution tabs, 32px rounded preview framing, and circular cyan outline navigation controls.

The right panel should show a selected company solution—not repeat the service name—through a solution-tab strip, a large visual preview, concise solution description, and cinematic transitions. The exported topology background should be used as the visual stage texture behind this interaction.

The exported preview uses a low-contrast navy interface scene with a bright 2px cyan perimeter; the content sits inside a rounded 32px frame. The companion icon is a cyan, translucent rounded-square service mark, which supports the reference’s luminous glass-panel hierarchy without introducing additional warm colors.
